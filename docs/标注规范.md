# CN-NewsTTS 标注规范

## 1. 标注目标

本规范用于构建中文新闻 TTS 读法 benchmark。标注员需要把新闻标题/摘要中的高风险读法片段识别出来，并给出可直接送入 TTS 的标准播报文本。

每条数据必须回答四个问题：

1. 哪些片段容易被 TTS 读错？
2. 这些片段属于什么读法类型？
3. 正确应该怎么读？
4. 最终送入 TTS 的 `spoken_text` 应该是什么？

---

## 2. 标注输出字段

每条样本使用以下结构：

```json
{
  "id": "case_000001",
  "source": "real_news",
  "domain": "sports",
  "raw_title": "湖人117-116险胜勇士",
  "raw_summary": "",
  "raw_text": "湖人117-116险胜勇士",
  "spoken_text": "湖人一百一十七比一百一十六险胜勇士",
  "risk_spans": [
    {
      "span": "117-116",
      "type": "sports_score_hyphen",
      "reading": "一百一十七比一百一十六",
      "wrong_readings": ["一百一十七到一百一十六"],
      "context_evidence": "出现湖人、勇士、险胜，属于体育比分"
    }
  ],
  "pronunciation_dict": {"tone": []}
}
```

字段说明：

- `raw_text`：原始新闻文本，通常为标题或标题+摘要。
- `spoken_text`：标准播报文本，是最终 TTS 输入。
- `risk_spans`：高风险片段列表。
- `type`：风险片段类别，必须从 `label_schema.json` 枚举中选择。
- `reading`：该片段正确读法。
- `wrong_readings`：已知错误读法，可为空。
- `context_evidence`：一句话说明判断依据。
- `pronunciation_dict`：需要发音词典控制的词，如外国人名、多音字、人名。

## 3. 通用标注原则

### 3.1 保持语义不变

只能改变读法表达，不能新增、删除或改写新闻事实。

正确：

```text
2025年 → 二零二五年
```

错误：

```text
2025年 → 今年
```

### 3.2 只标注高风险片段

普通汉字不需要标注。风险片段包括数字、缩写、型号、比分、单位、多音字、专名、符号等。

### 3.3 读法必须结合上下文

同一个表面形式在不同语境下读法可能不同。

```text
保时捷911 → 保时捷九幺幺
限量911台 → 限量九百一十一台
```

### 3.4 不确定项要标记

如果读法不确定，保留 `uncertain` 或在 `reviewer_note` 中说明，交由复核者裁决。

## 4. 类别标注规则

### 4.1 年份：`year_with_suffix` / `year_bare`

年份 1900-2099 按逐位读。

```text
2025年 → 二零二五年
2021年 → 二零二幺年
展望2025 → 展望二零二五
```

禁止：

```text
两千零二十五年
```

### 4.2 代际标签：`generation_label`

```text
80后 → 八零后
90后 → 九零后
00后 → 零零后
10后 → 一零后
```

禁止：

```text
八十后、九十后、幺零后
```

### 4.3 汽车/产品型号：`vehicle_model_number`

品牌或车型后面的型号数字通常逐位读。

```text
保时捷911 → 保时捷九幺幺
雷克萨斯GX550 → 雷克萨斯GX五五零
问界M9 → 问界M九
Q06 → Q零六
```

如果数字后接量词，则按数量读。

```text
限量911台 → 限量九百一十一台
降价911元 → 降价九百一十一元
```

### 4.4 数量和金额：`quantity_number`

数字后接元、台、辆、万人、亿元等量词时，按自然量级读。

```text
21440台 → 两万一千四百四十台
1.5万亿 → 一点五万亿
120亿元 → 一百二十亿元
```

### 4.5 百分比：`percentage`

百分号前置为“百分之”。

```text
38.5% → 百分之三十八点五
11% → 百分之十一
```

禁止读成“百分号”。

### 4.6 体育比分：`sports_score_colon` / `sports_score_hyphen`

体育比分中的 `:` 和 `-` 都读“比”。

```text
8:3 → 八比三
3:1 → 三比一
117-116 → 一百一十七比一百一十六
2-1险胜 → 二比一险胜
```

触发词：比分、战胜、击败、险胜、负于、半场、总比分、决赛、比赛、对阵、主场、客场。

禁止：

```text
8除3
117到116
117负116
```

### 4.7 区间：`range_hyphen`

非比分、非型号语境下的区间读“到”。

```text
3~5年 → 三到五年
10-20万 → 十到二十万
```

### 4.8 军事/装备型号：`military_model_hyphen`

装备、飞机、武器型号中的连字符不读，数字逐位读。

```text
苏-27 → 苏二七
歼-20 → 歼二零
J-20 → J二零
F-35I → F三五I
AK-47 → AK四七
```

禁止：

```text
苏负二十七
J负二十
F到三十五
```

### 4.9 Q1-Q4：`quarter_finance` / `quarter_product`

财经、财报、营收、净利、同比、环比语境读季度。

```text
腾讯Q1净利增长 → 腾讯第一季度净利增长
公司Q2营收 → 公司第二季度营收
```

产品、科技、汽车、型号、版本语境读字母+数字。

```text
问界Q1车型曝光 → 问界Q一车型曝光
新品Q3版本 → 新品Q三版本
```

### 4.10 固定英文缩写：`fixed_abbreviation`

以下缩写按业务固定读法逐字母读，不翻译。

```text
AI → A I
GDP → G D P
NBA → N B A
IPO → I P O
CEO → C E O
```

### 4.11 技术单位：`tech_unit`

```text
200km/h → 两百公里每小时
100m² → 一百平方米
40℃ → 四十摄氏度
500kW → 五百千瓦
800V → 八百伏
12Wh/km → 十二瓦时每公里
6.5L/100km → 百公里六点五升
```

### 4.12 外国人名：`foreign_name_pronunciation`

外国人名正文保持音译名，优先使用 `pronunciation_dict` 控制。

```json
{
  "span": "查尔斯",
  "type": "foreign_name_pronunciation",
  "reading": "查尔斯",
  "pronunciation_required": true,
  "pronunciation_entry": "查尔斯/(cha2)(er3)(si1)"
}
```

禁止把 `查尔斯国王` 读成 `zha尔斯国王`。

### 4.13 多音字：`polyphone_disambiguation`

多音字结合上下文判断，必要时用 `pronunciation_dict`。

```text
银行：hang2
行动：xing2
增长：zhang3
长期：chang2
供应：gong1
供词：gong4
```

### 4.14 标点和标题节奏：`title_pause` / `quote_book_symbol`

长标题可按语义断点增加逗号，但不能改变事实。

书名号和引号不读出。

```text
《黑神话》销量破亿 → 黑神话销量破亿
```

## 5. 标注流程

### 5.1 LLM 初标

先用 LLM 根据规则生成初稿：`spoken_text`、`risk_spans`、`pronunciation_dict`。

### 5.2 人工复核

人工重点检查：

- 是否漏标高风险片段。
- `type` 是否正确。
- `reading` 是否符合业务规范。
- `spoken_text` 是否完整且可直接送入 TTS。
- 是否有过度改写。

### 5.3 抽检和一致性

论文级数据建议 10%-20% 双人标注，计算一致性。冲突由资深标注者裁决。

---

## 6. 质量检查清单

标注完成前逐条检查：

- [ ] `raw_text` 和 `spoken_text` 语义一致。
- [ ] 所有数字、缩写、型号、比分、单位都已检查。
- [ ] `risk_spans` 不为空，且 span 能在 `raw_text` 中找到。
- [ ] `type` 来自 `label_schema.json` 枚举。
- [ ] `reading` 是该 span 的正确播报读法。
- [ ] 外国人名和多音字需要时已填 `pronunciation_dict`。
- [ ] 未把业务固定缩写翻译成中文含义。
- [ ] 未删除 `<#0.50#>` 等 TTS 停顿符。

---

## 7. MVP 标注建议

第一批建议做：

```text
500 条真实新闻 gold
5,000 条合成 hard cases
200 条真实/复现误读 case
```

优先覆盖：

1. 体育比分 `117-116`、`8:3`。
2. 军事型号 `苏-27`、`J-20`、`F-35I`。
3. 年份 `2025`、`2025年`。
4. 代际标签 `80后`、`90后`、`00后`、`10后`。
5. 财经和产品语境中的 `Q1-Q4`。
6. 固定缩写 `AI`、`GDP`、`NBA`。
7. 外国人名 `查尔斯`、`特朗普`、`德赫亚`。
